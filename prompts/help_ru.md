  Emelya — CLI AI Agent

  Просто напиши задачу или вопрос. Emelya использует инструменты для
  работы с файлами, кодом, архивами, документами и внешними сервисами.

  Используй @путь/к/файлу для ссылки на файл (Tab — автодополнение).
  Многострочная вставка из буфера обмена сворачивается в плейсхолдер.

  Команды:

  /help                  — эта справка
  /clear                 — очистить историю, начать новую сессию
  /compact               — сжать контекст (модель суммирует историю)
  /undo                  — откатить последнее изменение файла
  /drop N                — удалить сообщение N из контекста (/history для номеров)

  /rename <имя>          — переименовать текущую сессию
  /resume [имя]          — продолжить прошлую сессию (без аргумента — список)
  /branch [имя]          — создать ответвление разговора в новую сессию
  /export [путь]         — экспортировать разговор в текстовый файл

  /model                 — список моделей
  /model имя             — переключить модель
  /model add имя url модель [ключ]  — добавить модель

  /skill                 — список навыков
  /skill имя             — загрузить навык и выполнить
  /agent                 — список агентов
  /agent имя задача      — запустить агента с задачей

  /tools                 — показать загруженные инструменты
  /mcp                   — статус MCP серверов
  /mcp add имя команда   — подключить MCP сервер

  /commands              — список пользовательских команд
  /mycmd [аргументы]     — запустить команду (из .emelya/commands/mycmd.md)

  /stats                 — статистика токенов (сессия + проект)
  /context               — размер текущего контекста
  /history               — полный дамп контекста
  /exit                  — выход
  !<команда>             — выполнить команду напрямую (интерактивный TTY поддерживается)
  !|<команда>            — передать последний ответ модели в stdin команды (например, !|glow)

  Подсказки:

  - Модель сама выбирает инструменты и агентов для задачи
  - Для длинных задач модель может вызывать агентов (субпроцессы с изолированным контекстом)
  - Настройки проекта: emelya.md (в репо) и .emelya/config.md (личные)
  - MCP серверы подключаются лениво — при первом вызове
  - /compact полезен когда контекст разросся и модель начинает тормозить
  - Команды: добавь .md файлы в .emelya/commands/ (используй {args} как аргумент)
  - Память: добавь .md файлы в .emelya/memory/ — индексируются автоматически по первому заголовку
